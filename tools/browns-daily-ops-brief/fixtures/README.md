# Test Fixtures

This directory contains sample data for testing the Browns Daily Ops Brief CLI.

## Files

### `sample-day.json`

A complete day's bookings for testing, including:
- **2 arrivals** (one with late check-in flag)
- **2 in-house guests**
- **1 departure** (early checkout)

All names are fictional. Represents a typical day at Dullstroom The Browns Luxury Guest Suites.

**Format:** JSON array with booking objects

**Fields:**
- `guestName` (required) - Guest name(s)
- `suiteOrUnit` (required) - Suite assignment
- `status` (required) - One of: `arriving`, `inhouse`, `departing`
- `checkInDate` (optional) - ISO date
- `checkOutDate` (optional) - ISO date
- `lateCheckIn` (optional) - Boolean flag
- `adults` (optional) - Number of adult guests
- `children` (optional) - Number of children
- `notes` (optional) - Special requests or information

### `sample-facts.json`

Optional contextual information for the day (weather, staff notes, etc.).

**Format:** JSON object (key-value pairs)

**Example usage:**
```bash
npm run brief -- --day 2026-09-20 --bookings fixtures/sample-day.json --facts fixtures/sample-facts.json --outdir out/
```

## Creating Your Own Fixtures

### From Nightsbridge Screen Export

If you export guest data from Nightsbridge:

1. Open Nightsbridge dashboard for the target date
2. Copy guest names, suite assignments, and status
3. Format as JSON array following the structure in `sample-day.json`
4. Save to a new file (e.g., `bookings-2026-09-25.json`)

**Never commit real guest data to git.** Use this tool with actual data locally only.

### CSV Alternative

You can also create bookings as CSV:

```csv
guestName,suiteOrUnit,status,checkInDate,checkOutDate,lateCheckIn,notes,adults,children
Sarah & Tom Henderson,Luxury Suite 1,arriving,2026-09-20,2026-09-22,false,Anniversary celebration,2,0
```

## Testing with Fixtures

Run the fixture test:

```bash
npm run test:fixtures
```

This will:
1. Build the CLI
2. Generate a brief for 2026-09-20 using `sample-day.json`
3. Write outputs to `test-out/`
4. Exit with success

**Expected output files:**
- `test-out/draft-team-group-whatsapp.txt`
- `test-out/draft-guest-welcome-stubs/sarah-tom-henderson.txt`
- `test-out/draft-guest-welcome-stubs/the-mbeki-family.txt`
- `test-out/APPROVAL.md`
- `test-out/manifest.json`
